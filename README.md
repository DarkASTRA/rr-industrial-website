# R.R. Industrial Corporation Website

A modern, responsive corporate website for R.R. Industrial Corporation, a steel trading and distribution company serving infrastructure and industrial projects across India.

## Included

- Responsive premium industrial design
- Original R.R. Industrial logo preserved without cropping or alteration
- Product portfolio and sector coverage
- NBFC-backed trade-credit positioning
- Accessible mobile navigation
- Scroll-reveal interactions
- Email-based project enquiry form
- SEO-ready page metadata

## Local development

```bash
npm install
npm run dev
```

## Production build

```bash
npm run build
```

The generated production files are written to `dist/`.
